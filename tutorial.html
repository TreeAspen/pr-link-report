PR 链接报告生成器 · 使用教程

打开工具 →

把 Excel 表格或一串链接，变成带可点击超链接、媒体 Logo 和页面截图的传播报告。

这是什么

一个单文件的网页工具。你把媒体名称和转载链接粘进去，它排成一份传播报告页，导出的 PDF 里 每个媒体名都是可以点的超链接；也能复制进 Google Docs 继续编辑而链接不丢。

如果你手上有 EIN Presswire 之类的分发报告 PDF，配套脚本能把里面的媒体 Logo 抽出来、和链接域名建立对应关系。 之后你只要粘贴一串转载链接，媒体名称、所在地区、Logo 会自动补全。

工具完全在你自己的浏览器里跑，数据不上传任何服务器。关掉页面内容也还在（存在浏览器本地）。

三分钟上手

  1. 先看效果。点左栏「载入示例」，右侧会出现一份完整报告。随便点一段文字试试，可以直接改。
  2. 换成你的数据。点「粘贴 Excel / 链接清单，批量导入」，把你的表格或链接粘进去，点「生成」。
  3. 导出。点「打印 / 另存为 PDF」，在打印对话框里目标选「另存为 PDF」。链接在 PDF 里可以点。
不确定从哪下手时，先「载入示例」，照着示例的结构改，比从空白开始快得多。

导入数据

从 Excel 粘贴

在 Excel 或 Google Sheets 里选中区域 Ctrl+C，在弹窗的输入框里 Ctrl+V。 列会自动识别，你在下拉框里确认一下就行。典型的表长这样：

媒体名称地区链接分组
WIVB CBS 4Buffalo (NY)https://www.wivb.com/…独立媒体转载
WPIX CW 11New York City (NY)https://pix11.com/…独立媒体转载
Google Newshttps://news.google.com/…主要通讯社

映射里的「分组」是关键：指定这一列后，一次粘贴会自动拆成多个板块， 不用一组一组地导。

只有链接怎么办

直接粘一列光秃秃的链接就行。只要 Logo 图库里收录过这个域名，名称、地区、Logo 都会自己填上； 没收录的会退而显示域名本身，你再手动改名。

名称单元格自带超链接

很多人的表是「媒体名上挂着超链接」而没有单独的 URL 列。这种也认得——粘贴时会自动把单元格里的 超链接抽出来，在映射下拉框里显示成 ⟨某列 的超链接⟩，选它即可。

列映射说明

映射项作用
名称显示出来、可点击的文字，必填
副标题名称下面的小灰字，一般放地区，如 Buffalo (NY)
链接 URL点击后跳转的地址
图片 URL可选。若表里自带 Logo 图片地址
分组可选。指定后按此列拆成多个板块

已有板块也能追加：映射里不选分组列，在「无分组列时，写入」处选「追加到：某板块」。

版式

每个板块可以单独换版式，在左栏板块的 ✎ 里改。

版式长什么样适合
品牌方块 2/3/4 列有 Logo 就只显示 Logo，没有就显示加粗名称通讯社、搜索引擎那种一排品牌方块
卡片 1–4 列左边名称 + 地区，右边一个小 Logo电视台、报纸这类长列表

链接列表 · 3 列三栏项目符号链接，行优先排列频道、栏目这类纯文字长清单
圆角标签流式排列的小胶囊关键词、标签类
表格名称 / 说明 / 截图 / 链接四列需要把完整 URL 也印出来时

还有三种结构不同的区块，在「+ 新增」旁边的下拉框里选：

  • 世界媒体名录——灰底盒子，地区名 + 目标数 + 三栏媒体清单
  • 社交分享行——Facebook / X / LinkedIn / Bluesky 四格
  • 报告摘要面板——字数统计、锚文本链接、嵌入图片与图说

Logo 图库

这是「粘贴链接自动出图」的来源。在线版已经内置，直接就能用；本地要自己生成一次：

pip install -r requirements.txt

# 把你的传播报告 PDF 放进本目录，然后：
python extract_logos.py

脚本按 PDF 里链接注释的坐标定位每张媒体卡片，取出卡片内的 Logo、媒体名、所在地区， 与跳转域名建立对应关系，写进 logos.js。刷新页面后侧栏会显示「Logo 图库：N 家媒体 / M 张 logo」。

匹配顺序是：完整域名 → 逐级去掉子域 → 可注册域 → 媒体名称。www.、m.、amp. 这类前缀自动忽略。

  • 多跑几份不同的报告，图库会自动合并去重、越攒越全
  • 名字抓错了，改 logos_manifest.json 再跑一次脚本重建
  • 老项目想补 Logo，点「全文档按链接匹配 Logo」批量回填

配截图

三种方式，随手用哪种都行：

  1. 拖拽——图片文件直接拖到右侧某张卡片上。一次拖多张，从这张卡片起依次往下填
  2. 粘贴——先点一下要配图的条目（底部会出现选中条），再 Ctrl+V
  3. 批量——在板块设置里一次选几十张，按文件名自动匹配条目

文件名匹配的顺序：先精确匹配条目名称（忽略大小写和符号），再模糊包含匹配， 再认 01_xxx.png 这样的前缀编号，最后剩下的按顺序补空位。 所以把截图存成 WPIX CW 11.png 或 03_xxx.png 都能自动对上。

截图存在浏览器的 IndexedDB 里（localStorage 放不下），导入时自动压到宽 1400px。 侧栏底部会显示当前占用了多少空间。

编辑与主题

就地改字

右侧预览里的标题、媒体名、地区都能直接点进去改，改完自动保存。 注意：普通点击是编辑，Ctrl+点击才是跳转链接——否则点标题想改字会一直跳走。

主题配色

左栏「页头 / 品牌」里有一排配色方案，点一下整份报告的标题条和强调色就换了。 默认是藏青 + 品红。想要别的颜色，用下面两个取色器自己调。

页头

品牌名、副标题、Logo（选本地图片，会内嵌进文件，不依赖外链）、封面大图、页脚都能改。 勾上「生成目录」会在开头加一个目录，在 PDF 里点条目能跳到对应板块。

保存与迁移

内容自动存在浏览器本地，关掉再打开还在。要换电脑或做备份，用「保存项目」导出一个 .json——里面内嵌了所有截图，在另一台机器上「载入项目」即可完整还原。

常见问题

点媒体名跳走了，没法改字

普通点击是编辑，Ctrl+点击才跳转。如果反了，说明你按住了 Ctrl。

刷新后截图没了

截图存在 IndexedDB 里。浏览器处于隐私模式、或站点数据被清除时会丢。重要项目请用「保存项目」导出 JSON 备份。

复制到 Google Docs 后图片没过去

图片能否随粘贴一起过去取决于浏览器，链接一定不会丢。图片没过去就用「导出全部截图为图片文件」拿到原图手动插入， 文件名的编号和报告顺序是一致的。

侧栏显示「尚无 Logo 图库」

本地版需要先跑 python extract_logos.py 生成 logos.js。在线版是内置的， 出现这个提示说明文件没加载出来，刷新一次试试。

导出的 PDF 把卡片从中间切断了

卡片本身设了禁止跨页断开。如果是某个超长板块被切开，可以把它拆成两个板块，或换成更紧凑的版式。

粘贴 Excel 后列对错了

在弹窗的五个下拉框里手动改映射，下面的预览表会实时跟着变，确认无误再点「生成」。

What this is

A single-file web tool. You paste in outlet names and reprint URLs, it lays them out as a distribution report, and the exported PDF keeps every outlet name as a working hyperlink. You can also copy the whole thing into Google Docs and keep editing there without losing the links.

If you have a distribution-report PDF from EIN Presswire or similar, the companion script pulls the outlet logos out of it and pairs them with link domains. After that, pasting a bare list of reprint URLs is enough — names, locations and logos fill themselves in.

Everything runs in your own browser. Nothing is uploaded, and your work survives closing the page (it is stored locally).

Three-minute start

  1. See it working. Click Load sample in the sidebar. A complete report appears on the right — click any text to edit it in place.
  2. Swap in your data. Click Paste Excel or a list of links, paste your table or URLs, then Create.
  3. Export. Click Print / Save as PDF and choose “Save as PDF” as the destination. The links stay clickable.
When in doubt, load the sample first and edit it — far quicker than starting from a blank page.

Importing data

Paste from Excel

Select a range in Excel or Google Sheets, press Ctrl+C, then press Ctrl+V in the dialog’s text box. Columns are detected automatically — just confirm the mapping. A typical sheet looks like this:

OutletLocationLinkGroup
WIVB CBS 4Buffalo (NY)https://www.wivb.com/…News platforms
WPIX CW 11New York City (NY)https://pix11.com/…News platforms
Google Newshttps://news.google.com/…Major newswires

The Group mapping is the useful one: point it at a column and a single paste is split into several sections at once.

When you only have links

Paste a bare column of URLs. For any domain the logo library knows, the name, location and logo are filled in for you; unknown domains fall back to showing the domain itself, which you can then rename.

Hyperlinks inside the name cells

Many sheets carry the URL as a hyperlink on the outlet name rather than in its own column. That works too — the hyperlink is extracted on paste and offered in the mapping dropdowns as ⟨hyperlink of column N⟩.

What each mapping does

Logo library

This is what powers “paste a link, get a logo”. The hosted version already includes it. Locally you generate it once:

pip install -r requirements.txt

# put your distribution-report PDF in this folder, then:
python extract_logos.py

The script uses the coordinates of the PDF’s link annotations to locate each outlet card, then pairs the logo inside it with the outlet name, location and target domain, writing everything to logos.js. Reload and the sidebar reports Logo library: N outlets / M logos.

Matching order: exact domain → strip sub-domains one level at a time → registrable domain → outlet name. Prefixes like www., m. and amp. are ignored.

  • Run several different reports through it and the library merges, de-duplicates and grows
  • If a name came out wrong, fix logos_manifest.json and re-run the script
  • To backfill an older project, click Match logos by link across document

Adding screenshots

Three ways, use whichever is closest to hand:

  1. Drag an image file onto a card. Drop several and they fill consecutive entries
  2. Paste — click the entry first (a bar appears at the bottom), then Ctrl+V
  3. Bulk — select dozens at once in the section settings; they are matched by filename

Filename matching goes: exact match on the entry name (ignoring case and punctuation) → fuzzy contains → a numeric prefix such as 01_xxx.png → whatever is left fills the remaining slots in order. So naming a file WPIX CW 11.png or 03_xxx.png both work.

Screenshots live in the browser’s IndexedDB (localStorage cannot hold them) and are resized to 1400px wide on import. The sidebar footer shows how much space they use.

Editing and theming

Editing in place

Titles, outlet names and locations in the preview are directly editable and save as you type. Note that a plain click edits and Ctrl+click follows the link — otherwise clicking a heading to fix a typo would navigate away.

Theme colours

Under Header & branding there is a row of colour presets; one click restyles the whole report. The default is navy with a magenta accent. For anything else, use the two colour pickers below.

Header

Brand name, tagline, logo (a local file, embedded into the document rather than linked), cover image and footer are all editable. Ticking Table of contents adds a contents block whose entries jump to the matching section inside the PDF.

Saving and moving

Your work is stored in the browser automatically. To move machines or keep a backup, use Save project to export a .json — it has every screenshot embedded, so Load project on another machine restores the whole thing.

Troubleshooting

Clicking an outlet name navigates away instead of editing

A plain click edits; Ctrl+click follows the link. If it behaves the other way round, Ctrl is held down.

Screenshots disappeared after reloading

They live in IndexedDB, which is cleared in private windows or when site data is wiped. For anything important, export a JSON backup with Save project.

Images did not come through to Google Docs

Whether images travel with the paste depends on the browser; the links always survive. If the images did not make it, use Export all screenshots as files and insert them manually — the filename numbering follows the report order.

The sidebar says there is no logo library

Locally you need to run python extract_logos.py once to produce logos.js. The hosted version ships with it, so if you see this there, the file failed to load — try reloading.

The exported PDF splits a card across pages

Cards are set not to break across pages. If a very long section is being split awkwardly, divide it into two sections or switch to a more compact layout.

The columns came out wrong after pasting

Fix the five mapping dropdowns in the dialog — the preview table below updates live, so you can check before clicking Create.
